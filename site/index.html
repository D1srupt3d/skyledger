skyledger GitHub

A ledger of everything your ADS-B receiver has heard.

skyledger sits next to your readsb + tar1090 receiver and keeps what it hears: live positions, the history readsb already recorded, every flight, your reception range and your receiver's health. It stores it in TimescaleDB and shows it in Grafana.

The live demo is the web UI skyledger is getting next, running on a made-up receiver on the South Downs in southern England. Nothing to install.

What it keeps

Your receiver's own history

readsb's heatmap already holds a replay of every aircraft, but only tar1090 can read it and a container restart can wipe it. skyledger imports every day it can find, then adds each new day nightly and keeps it forever.

Live positions

Every 10 seconds, including what aircraft report beyond position: wind and temperature aloft, airspeeds, autopilot targets, emergency state and GPS integrity.

Flights

A searchable flight log built from the history, with flights per day, a weekday by hour grid, regulars, rare visitors and first-ever sightings.

Reception range

An all-time outline of the furthest you've heard in every direction, with bad decodes filtered out, plus range by bearing and a coverage heatmap.

Receiver health

Signal, noise, strong signals, message rate and gain, and GPS interference when it shows up.

Read-only on your receiver

skyledger only ever reads from tar1090 over HTTP, and paces its history downloads so your receiver isn't hammered.

How it works

Four containers next to your receiver. ingest reads the live feed every 10 seconds, history imports readsb's heatmap once and then nightly, and Grafana reads the database with a read-only login.

Quick start

You need a readsb + tar1090 receiver you can reach over HTTP, and Docker with Compose or a Kubernetes cluster. Put the database on an SSD, not an SD card.

Docker Compose

Copy .env.example to .env, set TAR1090_URL, TZ and the three passwords, then start it. Grafana is on port 3000.

git clone https://github.com/D1srupt3d/skyledger.git
cd skyledger
cp .env.example .env
docker compose up -d

Kubernetes with Helm

helm install skyledger oci://ghcr.io/d1srupt3d/charts/skyledger \
  --namespace skyledger --create-namespace \
  --set tar1090Url=http://ultrafeeder/ --set timezone=Europe/London

Try it without a receiver

With the passwords set in .env, this starts a demo feed with a week of made-up history.

TAR1090_URL=http://demo-feed:8080/ COMPOSE_PROFILES=grafana,demo docker compose up -d

Connecting to ultrafeeder or adsb.im, using your own Grafana or database, and every setting: read the full README.
